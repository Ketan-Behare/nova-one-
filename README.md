# NOVA ONE — 3D Interactive Product Landing Page

Fictional premium product landing page built with React, Three.js and React Three Fiber.

## Features
- Full-screen cinematic hero
- Interactive 3D product
- Scroll-linked product rotation/position
- Glassmorphism UI
- Mouse/touch orbit interaction
- Realistic lights, materials and contact shadows
- Responsive layout
- Reduced-motion support
- No paid APIs or services

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
